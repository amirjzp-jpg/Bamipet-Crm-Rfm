# Bamipet — Messaging Architecture · معماریِ پیام‌رسانی (Level 2)

> **How to use this file.** This is the operating system that connects *strategy* (foundation, value props) to *actual messages*. For any messaging or campaign task:
> 1. Identify the **persona** (default نگار) → take her **lead pillar and angle** (see *Message Angle per Persona*).
> 2. Identify the **journey stage** the content serves (see *Message by Journey Stage*) → adjust emphasis accordingly.
> 3. Pull supporting facts from the **Reasons-to-Believe Library** under the relevant pillar.
> 4. Write in the voice and format from `bamipet-voice-message-copy.md`; everything must still resolve to the **roof message** (خیالِ راحت).
> 5. Obey all Non-Negotiable Rules (no money/فروش language, no self-praise, dignity in language) — this file inherits them, it doesn't relax them.
>
> Pairs with `bamipet-foundation.md`, `bamipet-personas.md`, and `bamipet-voice-message-copy.md`. This file operationalizes the **Value Proposition Hierarchy** — the four pillars below are identical to the four value props, viewed as message themes rather than customer-experience benefits.

---

## What This Adds

Three existing documents already answer *who* (personas), *what* (value props), and *how* (voice/copy). This file adds the piece that was still missing: **which message, for whom, in what order, backed by what proof** — the actual planning layer a marketer or the model reaches for when building a specific campaign or piece of content.

## Part One — The Message House · خانهٔ پیام

A single structure unifying every message Bamipet sends.

### سقف · Roof — The One Controlling Message
> **با بامی‌پت، با خیالِ راحت از همراهت مراقبت می‌کنی.**
> *With Bamipet, you care for your companion with peace of mind.*

Every piece of content, regardless of pillar or persona, ultimately serves this one line. If a draft doesn't ladder up to it, it's off-architecture.

**جوهره / Essence carried by the roof:** خیالِ راحت (peace of mind).

### ستون‌ها · Pillars — The Four Message Themes
*(Identical to the four Value Propositions — same content, viewed here as message themes rather than customer benefits. Do not invent parallel themes; always route through these four.)*

| # | ستون | پیامِ مشتری |
|---|---|---|
| ۱ | راهنماییِ صادقانه و دلسوز | همون‌قدر که تو همراهتو دوست داری، ما هم به فکرشیم. |
| ۲ | بررسی‌شده و اصل | هرچه به دستت می‌رسه، مطمئن و اصله. |
| ۳ | خیالِ راحت از انتخاب *(the wedge / hero)* | با خیالِ راحت انتخاب کن؛ هر چی برای همراهت لازمه، همینجاست. |
| ۴ | در تمامِ مسیر کنارتیم | از روزِ اول تا روزهای سخت، یه متخصصِ دلسوز کنارته. |

## Part Two — Message Angle per Persona · زاویهٔ پیام برای هر پرسونا

The same house, aimed differently per audience. Full persona detail lives in `bamipet-personas.md`; this section is the *messaging* application of that detail.

### نگار — لید: ستونِ ۳ (خیالِ راحت از انتخاب)
**زاویه:** آرام‌سازی. اول نگرانی‌اش را ببین، بعد اطمینان بده که دارد درست عمل می‌کند.
**پیامِ لید:** «تو داری درست انجامش می‌دی؛ با خیالِ راحت انتخاب کن.»
**چرا این ستون:** او به دنبالِ تأیید است، نه دادهٔ بیشتر — رفعِ گناه و تردید، پیش از هر چیز.

### سارا — لید: ستونِ ۲ (بررسی‌شده و اصل) + عمقِ ستونِ ۱
**زاویه:** اثباتِ تخصص. با جزئیات و شفافیت احترام بگذار؛ او با برهان متقاعد می‌شود، نه با آرام‌سازی.
**پیامِ لید:** «چرا این انتخاب درسته — با جزئیاتِ ترکیبات و کیفیت.»
**چرا این ستون:** او دلشورهٔ تازه‌کاری ندارد؛ به دنبالِ هم‌کلامِ متخصص است.

### کیان — لید: ستونِ ۴ (در تمامِ مسیر کنارتیم) + ستونِ ۲
**زاویه:** اطمینانِ تأمین و احترامِ بی‌قضاوت. مطمئن، بی‌دردسر، بدونِ قضاوت دربارهٔ سگ‌داری.
**پیامِ لید:** «هر چی سگت لازم داره — مطمئن، بی‌دردسر، و همیشه سرِ وقت.»
**چرا این ستون:** اولویتِ او تداومِ تأمین (ارسال به خانه) و احترام است، نه آموزشِ پایه.

### امیر — لید: ستونِ ۲ (بررسی‌شده و اصل)
**زاویه:** کارایی و اصالت. سریع، روشن، بی‌ابهام — بدونِ مقدمه‌چینیِ احساسی.
**پیامِ لید:** «اصل، مطمئن، سریع — بی‌دردسر به دستت می‌رسه.»
**چرا این ستون:** او دنبالِ سرعت و اطمینانِ اصالت است، نه روایتِ گرم و طولانی.

## Part Four — Message by Journey Stage · پیام در هر مرحله از سفر

A second, independent axis from the "What to Lead With, Where" surface-map in `bamipet-voice-message-copy.md`. That map answers **where** (homepage, IG, ads, support); this answers **when in the funnel**. Use both together: a homepage banner at the awareness stage and a homepage banner at the decision stage carry different emphasis even on the same surface.

| مرحله | ستون‌های پیش‌رو | هدف |
|---|---|---|
| **۱ · آگاهی** *(Awareness)* | خیالِ راحت (۳) | جلبِ توجه با جوهرهٔ برند؛ بی‌فشار، صرفاً طرحِ حس. |
| **۲ · سنجش** *(Consideration)* | راهنمایی (۱) + اصالت (۲) | ساختِ اعتماد از طریقِ آموزش و شفافیت. |
| **۳ · تصمیم** *(Decision)* | اصالت و ضمانت (۲) + خیالِ راحت (۳) | رفعِ آخرین تردید، همچنان بدونِ فشارِ فروش. |
| **۴ · وفاداری** *(Loyalty)* | همراهیِ بلندمدت (۴) | تعمیقِ رابطه؛ موتورِ تبلیغِ دهان‌به‌دهان. |

**کاربردِ عملی:** یک کپشنِ آموزشیِ عمومی برای نگار در مرحلهٔ سنجش → ستون‌های ۱+۲؛ همان موضوع در یک ایمیلِ فالو-آپ بعد از خرید (مرحلهٔ وفاداری) → ستونِ ۴.

## How to Apply This File — Worked Example

*A model or writer using this file for a real task should reason like this:*

**Task:** "Write an Instagram caption encouraging نگار to trust a domestically-made cat litter."

1. **Persona:** نگار → lead pillar ۳ (خیالِ راحت از انتخاب), angle = reassurance.
2. **Journey stage:** likely سنجش (Consideration — she's comparing, not yet decided) → blend in pillar ۲ (اصالت) as support.
3. **RTB pull:** from pillar ۲ — «گزینش از میانِ محصولاتِ داخلی و وارداتی»; from pillar ۳ — «گزینهٔ مناسب برای هر همراه».
4. **Voice + template:** use the message formula (نگرانی را ببین → راهنمایی → خیالِ راحت) and the Instagram caption template from `bamipet-voice-message-copy.md`.
5. **Check against Non-Negotiable Rules:** no مصرف of price words; the domestic-vs-imported framing must NOT imply "domestic = the cheap fallback" — frame as "vetted regardless of origin," consistent with the Onliness Statement (see Notes below).

## Notes

- **Pillars = value props, deliberately.** Inventing separate "message themes" would fragment the system into two parallel structures saying the same thing differently. One system, viewed from two angles (customer benefit vs. message architecture).
- **The domestic/imported framing:** Bamipet carries both; never frame domestic as merely "the affordable alternative to imports." The correct frame — consistent with the Onliness Statement — is that Bamipet applies honest vetting **across** both categories. Any content pillar or message touching this (e.g., a future "how to choose well" content topic) must avoid the false binary.
- **Onliness Statement** *(locked, not yet given its own document — recorded here for reference until placed)*:
  > بامی‌پت تنها برندِ مراقبتِ حیوانات در ایران است که، از میانِ محصولاتِ داخلی و وارداتی، با مشاورهٔ صادقانه به سرپرست کمک می‌کند گزینهٔ درست را — قابلِ‌اعتماد و منطقی — پیدا کند؛ بدونِ آنکه مجبور باشد بینِ اعتماد و دسترس‌پذیری یکی را انتخاب کند.
  Internal/strategic use only (like the Positioning statement) — never customer copy. Standing principle attached to it: *any sentence naming a limitation must locate that limitation in the market/competitors, never in the guardian.*
- **Next in the brand book sequence:** Brand Story (on hold, per current direction) → Elevator Pitches → Brand Architecture & Naming Conventions → Visual Guidelines → In-Store Experience Standards.
