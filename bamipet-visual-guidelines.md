# Bamipet — Visual Identity Guidelines · راهنمای بصری (Level 3 · Working Version)

> **How to use this file.** This is Bamipet's visual system — the working version, sufficient to brief content creation, mockups, and a Figma design-token system. For any visual task:
> 1. Never alter the **logo mark** itself — only its color variant, size, and placement, per the rules below.
> 2. Use the **exact hex values** given — don't approximate or "close enough" a color.
> 3. Every visual choice should serve the same job the voice does: **calm the worry.** If a choice reads busy, cold, or salesy, it's wrong even if it's attractive.
> 4. Farsi typography = **Vazirmatn**. Latin/English/data = **Inter**. Never swap these roles.
> 5. This is the **working version** — sufficient for social content, basic mockups, and web use. A full production system (packaging, print, signage specs, motion) still needs a dedicated Figma pass.
>
> Pairs with `bamipet-foundation.md` (strategy), `bamipet-voice-message-copy.md` (verbal identity), and `bamipet-content-pillars.md` (what this visual system dresses).

## Governing Principle

Every brand decision so far — the essence (خیالِ راحت), the voice (warm-but-composed), the value props — points at one job: **resolve anxiety into calm.** The visual system exists to do the same thing wordlessly. Warm, uncluttered, generously spaced, honest imagery. Never bold-for-attention, never cold-for-premium, never busy-for-energy.

**Direction chosen:** *خیالِ راحت / Calm-Trust* — composed and warm, anchored in the brand's own blue. (Two other directions were considered and rejected: a warmer/cuter "friend-first" direction risked tipping into cuteness over reassurance; a colder "confident-premium" direction was rejected outright as inconsistent with Bamipet's accessible, non-luxury positioning.)

## Logo System

**The mark itself never changes.** It stays exactly as designed — a rounded dog silhouette in the brand blue. What this section governs is *how it's used*, not what it looks like.

**Note on the mark:** the logo depicts a dog, while Bamipet's customer base and content are cat-first. This is not corrected by altering the logo — it's resolved by weighting photography and content cat-forward (see *Photography*), so the *living brand* reads as "all companions" even though the fixed mark is one dog.

### Color Variants
- **Brand blue on light backgrounds** (default/primary use)
- **White on dark or photo backgrounds** (never the blue mark on a dark background — contrast fails)
- **Ink** (`#1A1E2E`) — rare, print-only, single-color contexts

### Clear Space
Minimum clear space around the mark on all sides = the height of the mark's small triangular ear. Nothing — text, other graphics, edge of frame — enters this space.

### Minimum Size
Do not render the mark below a size where the ear-notch and the step-cut silhouette remain crisply legible (roughly 24px / 0.5cm at typical screen/print resolution).

### Misuse — never do these
- **Never stretch or compress** the mark in either dimension.
- **Never rotate** the mark.
- **Never recolor** outside the three sanctioned variants (blue / white / ink).
- **Never add effects** — no drop shadows, gradients, outlines, or bevels.
- **Never place the blue mark directly on a busy photo** without a solid-color safe zone behind it.

## Color Palette

The palette is built *from* the logo's blue — not invented separately. Warm cream (not stark white) delivers the calm; amber is reserved for meaning, not decoration.

| Role | Name | Hex | Usage |
|---|---|---|---|
| Primary | آبیِ بامی‌پت / Bamipet Blue | `#1C48C1` | The mark, key buttons, primary headings — the fixed anchor of the identity |
| Primary deep | آبیِ عمیق / Blue Deep | `#123086` | Emphasis text, dark backgrounds (business cards, footers) |
| Primary soft | آبیِ نرم / Blue Soft | `#2E5BE0` | Lighter touches, hover states, secondary accents |
| Base | کِرمِ گرم / Warm Cream | `#FAF9F6` | Dominant background. **Never pure white** — warmth is the point. |
| Base 2 | کِرمِ تیره‌تر / Cream 2 | `#F4F2EC` | Secondary background, card fills |
| Accent (meaning) | عسلی / Honey Amber | `#B77E33` | **Reserved** for trust/approval moments only — "تأییدِ بامی" seals, verified badges. Never purely decorative. |
| Affirmative | سبزِ آرام / Calm Green | `#2F8F6B` | Health-positive, wellness, "do" moments. Calm nature-green, not clinical-medical green. |
| Text | جوهری / Ink | `#1A1E2E` | All body text. **Never pure black** — softer and warmer on the eye. |

### Usage Ratio (guideline for any single layout)
Cream/base ~55% · Blue ~25% · Ink ~10% · Amber ~6% · Green ~4%

This ratio is what keeps pages feeling calm rather than "branded at" — blue and amber are accents on a warm neutral field, not competing for dominance.

## Typography

| Role | Typeface | Notes |
|---|---|---|
| Farsi — display & body | **Vazirmatn** | Weights 300–800. Warm, rounded, highly legible in Persian. Used for everything Farsi: headlines through body copy. |
| Latin — labels & data | **Inter** | English labels, numerals, technical/data contexts. Never used for a primary Farsi headline. |

### Type Scale (reference)
| Level | Size | Weight |
|---|---|---|
| H1 | ~56px | Vazirmatn ExtraBold (800) |
| H2 | ~34px | Vazirmatn Bold (700) |
| H3 | ~20px | Vazirmatn SemiBold (600) |
| Body | ~16px | Vazirmatn Regular (400) |
| Label/caption | ~11–12px | Inter Medium/SemiBold, often uppercase with letter-spacing |

**Principle:** generous line-height and spacing always — calm ≠ cramped. Headlines are confident but never shout (no excessive weight/size just for attention).

## Iconography

Simple, single-weight, rounded line icons — echoing the geometric softness of the logo mark itself. Icons explain; they never decorate for decoration's sake. Avoid: sharp/technical icon sets, cartoonish or novelty icon sets, filled/heavy icons that fight the light overall palette.

---

## Photography Direction

**Principle:** candid and honest beats polished and staged. This is also the current (2026) signal that separates authentic brands from AI-polished, generic content — real, natural-light moments read as trustworthy in a way stock photography no longer does.

**Do:**
- Candid, unposed moments — not staged "look at camera" shots
- Natural, window/ambient light — warm tones, not cold studio lighting
- Both the guardian *and* the companion in frame together where possible
- Feature both cats and dogs — but **weight photography cat-forward**, consistent with the actual customer base, to balance the fact that the fixed logo mark is a dog

**Don't:**
- Generic, glossy stock photography
- Cold studio lighting or clinical framing
- Over-saturated filters or heavy color grading
- Fully artificial/staged scenes

## Applications (Working Examples)

The system as briefed should hold up across at least these four touchpoints:

- **Instagram post** — cream/photo-led visual, brand-blue UI accents, caption in Vazirmatn voice (see `bamipet-voice-message-copy.md` for caption templates)
- **Product tag** — mark + wordmark, white/cream ground, amber "تأییدِ بامی" seal only where genuinely earned
- **Business card** — dark (blue-deep) or light treatment, white or blue mark accordingly, minimal — name, role, one contact line
- **Storefront signage** — mark + wordmark at large scale on cream or blue, maximum legibility, minimum clutter

## Design Tokens (for Figma / code handoff)

| Token | Value | Use |
|---|---|---|
| `space-xs` | 4px | Tight internal spacing |
| `space-sm` | 8px | Between closely related items |
| `space-md` | 16px | Standard spacing |
| `space-lg` | 32px | Between minor sections |
| `space-xl` | 64px | Between major sections |
| `radius-sm` | 4px | Cards, tags, subtle rounding |
| `radius-md` | 8px | Larger cards, modals |
| `radius-full` | 999px | Pills, chip buttons |

These are a starting reference for translating the system into real Figma variables/styles — not yet a full production token library.
